# v0.1.0

## Included

- Two installable Agent Skills for local course-video production and safe
  multi-platform draft preparation.
- Generic ordered keyword policy with explicit episode extensions.
- FFmpeg demo adapter with H.264/AAC output, subtitle burn-in, and horizontal
  or vertical scaling/padding.
- Full package checks for manifest hashes, safe relative paths, media streams,
  duration, and cover dimensions.
- Draft state guardrails that stop at unpublished states.
- AiToEarn fixed allow-list read-only capability queries.
- Synthetic copyright-free demo assets and preview-first installation.

## Explicitly out of scope

No upload, public submission, scheduling, deletion, comments, browser
automation, upload signing, asset confirmation, or Flow creation is included.
