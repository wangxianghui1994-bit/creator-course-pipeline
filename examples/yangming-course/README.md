# Yangming course metadata example

This directory contains metadata-only examples. It does not contain real
course media, NotebookLM conversations, private URLs, accounts, or drafts.

`source-provenance.example.json` shows the optional NotebookLM provenance
contract with a sanitized placeholder reference. Replace the reference with a
private trace-ledger ID in a local project; do not put a real private URL or
credential in a public package.
